# SDN Designer

[English](./README.en.md) | 中文

纯前端、拖拽式的虚拟网络设计器。通过拖拽节点与连线，可视化搭建虚拟网络拓扑，并一键导出 **OVN 命令行脚本** 或 **多云 Terraform** 资源定义（阿里云 / 腾讯云 / AWS / 华为云）。

## 特性

- 🖱️ 拖拽式画布：从左侧节点库拖入节点，拖动连接点完成连线，支持缩放、平移、小地图。
- 🧭 内置示例：首次访问自动载入示例拓扑（VPC + 交换机 + ECS + 安全组 + EIP + 密钥对），工具栏「加载示例」可随时重新载入。
- 🔀 连接校验：只允许合法的网络关系（如 VM 挂载到逻辑交换机、VPC 包含子网等）。
- 🖥️ OVN 逻辑网络：逻辑交换机 / 逻辑路由器 / 虚拟机 / 宿主机（Chassis，可配置网卡与隧道封装）。
- ☁️ 多云资源：切换阿里云 / 腾讯云 / AWS / 华为云，覆盖 VPC / 子网 / 网关 / 弹性公网 IP / 安全组 / 实例 / 路由表 / 密钥对。
- 🔗 多 VPC 互联：拖入「对等连接」节点并连接多个 VPC，导出时按两两全互联生成对等连接，并为各 VPC 的路由表自动补全路由。
- 🧩 实例配置：镜像与规格为可编辑下拉（本地内置清单 + 在线清单合并），支持计费方式、系统盘 / 数据盘（类型、容量）与登录认证。
- 🔑 密钥对节点：`Instance → KeyPair` 连线绑定实例，可选择「新建密钥对」（由 Terraform 生成并保存私钥）或「关联现有密钥对」（引用云上已有密钥）；绑定后实例编辑器隐藏内联密钥对字段。
- 🧾 创建后属性输出：可勾选资源 ID、公网 IP 等云上创建后才可知的属性，导出时生成 `output.tf`。
- 🕸️ 隧道网络：宿主机之间隧道互联，自动形成「区域」；逻辑交换机可部署到区域内的所有节点。
- 📤 双格式导出：
  - **OVN**：生成 `ovn-nbctl` / `ovs-vsctl` / `ovn-sbctl` 命令脚本。
  - **Terraform**：按所选厂商生成资源定义（资源引用、下一跳自动解析、系统盘/数据盘、密钥对新建或关联现有；勾选属性后额外生成 `output.tf`），并在导出时校验可用区与地域是否匹配。
  - 多文件结果可一键打包为 ZIP 下载；Terraform 导出弹窗可选填云厂商凭证（写入 `variables.tf` 默认值，留空则走环境变量，注意生成文件含密钥勿提交）。
- 🌐 国际化：中英文双语，右上角一键切换，偏好保存在本地。

## 快速开始

```bash
npm install     # 安装依赖
npm run dev     # 开发服务器 http://localhost:5173/
npm run build   # 生产构建
npm run preview # 预览生产构建
```

## 使用方式

1. 在顶部工具栏选择云厂商（阿里云 / 腾讯云 / AWS / 华为云），云资源节点的命名与导出将随之变化。
2. 从左侧「节点库」拖入节点到画布；首次访问会自动载入内置示例，也可点击工具栏「加载示例」重新载入。
3. 拖拽节点右侧连接点到目标节点左侧，建立连线（非法关系会被忽略）。
4. 双击节点（或选中后点右侧「编辑」）在弹窗中编辑名称、网段、IP、规则等；实例的镜像与规格可从下拉列表选择或直接输入。
   - 实例可编辑系统盘 / 数据盘；并在「导出输出」中勾选资源 ID、公网 IP 等创建后才可知的属性。
   - 拖入「宿主机」时会先弹出创建对话框，需填写节点名称与网卡信息（可勾选隧道封装网卡）。
5. 绑定密钥对：将实例连到「密钥对」节点，并在其属性中选择「新建密钥对」或「关联现有密钥对」。
6. 点击顶部「导出 OVN 命令」或「导出 Terraform」查看并复制 / 下载结果（勾选输出属性时会多出 `output.tf`）。

### 搭建跨物理节点的逻辑网络

1. 拖入多个「宿主机」，两两连线（隧道互联）形成「区域」。
2. 拖入「逻辑交换机」，将其连到区域内的任意宿主机（部署到节点）。
3. 拖入「虚拟机」，连线挂载到逻辑交换机。
4. 导出 OVN 命令，脚本会为区域内的所有宿主机生成隧道封装配置，并标注交换机的部署范围。

## 支持的节点

| 分类 | 节点 | 说明 |
| ---- | ---- | ---- |
| OVN | 逻辑交换机 | 二层广播域，携带子网 CIDR |
| OVN | 逻辑路由器 | 三层转发，可标记外部网络 |
| OVN | 宿主机 Chassis | 物理节点，可配多网卡 + 隧道封装 |
| OVN | 虚拟机 | 逻辑端口，含 IP / MAC |
| 云 | VPC | 专有网络网段 |
| 云 | 交换机 VSwitch | VPC 内子网 + 可用区 |
| 云 | 网关 | NAT 网关 |
| 云 | 弹性公网 IP | 独立 EIP，可绑定到实例 |
| 云 | 安全组 | 入/出方向规则 |
| 云 | ECS 实例 | 镜像、规格、计费方式、登录认证、私网 IP |
| 云 | 路由表 | 路由条目与下一跳 |
| 云 | 对等连接 | 连接多个 VPC，导出为 VPC Peering |
| 云 | 密钥对 | 登录密钥对，绑定实例（新建 / 关联现有） |

## 实例镜像与规格清单

实例的「镜像」与「实例规格」以本地内置清单为基底，可选叠加在线清单（按 `value` 合并、在线覆盖同项）：

- 本地内置：`src/data/images.js`、`src/data/instanceTypes.js`。
- 在线清单通过构建时环境变量注入，详见 [`.env.example`](./.env.example)：
  - `VITE_CATALOG_URL`：远程 JSON，结构 `{ "images": { "<vendor>": [{ "value", "label" }] }, "instanceTypes": { ... } }`，可只提供部分厂商。
  - `VITE_CATALOG_API_URL`：厂商 API 代理地址，见下方「配置厂商 API 代理」。
- 在线拉取失败时自动回退本地清单，离线可用。

### 配置厂商 API 代理

浏览器直连云厂商 API 需要处理 AK/SK 签名与 CORS，建议由后端代理调用厂商接口、返回规范化结果。

1. 复制 [`.env.example`](./.env.example) 为 `.env`，设置 `VITE_CATALOG_API_URL`（`VITE_` 前缀变量在构建时注入）。
2. 代理地址支持两种模式（实现见 `src/store/catalog.js` 的 `loadFromApi`）：
   - **按需请求**：URL 含 `{vendor}` / `{kind}` 占位符时，会对 4 个厂商（`aliyun` / `tencent` / `aws` / `huawei`）× 2 种类型（`images` / `instanceTypes`）分别发起请求，例如：
     ```bash
     VITE_CATALOG_API_URL=https://catalog.example.com/api/{kind}/{vendor}
     ```
   - **完整清单**：URL 不含占位符时，视为一次返回 `{ "images": { "<vendor>": [...] }, "instanceTypes": { ... } }`。
3. 每个清单项可以是字符串，或 `{ value, label }`（也兼容 `{ id, name }`）；响应可直接返回数组，或包在 `{ "items": [...] }` / `{ "values": [...] }` 中。

## 项目结构

详细目录结构与数据模型见 [`PROJECT_STRUCTURE.md`](./PROJECT_STRUCTURE.md)。

```
src/
├── App.vue        # 主编排
├── store/         # 设计器状态 / 云厂商 / 清单（本地 + 在线）
├── data/          # 节点定义、厂商、地域、计费、磁盘、输出、示例、镜像、规格
├── nodes/         # 节点组件
├── components/    # 侧栏 / 工具栏 / 属性面板 / 弹窗
├── export/        # OVN 导出 + 按厂商的 Terraform 导出（纯函数）
└── i18n/          # 中英文案
```
